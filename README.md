# ⚡ Featured Projects

### ⚡ ElectroVerse — AI-Powered Learning Assistant
A domain-specific RAG assistant for *Fundamentals of Electric Circuits* using Gemini API and ChromaDB. Features include textbook-grounded Q&A, study plan generation, chapter summaries, and practice question generation.

### 🧠 AI Life Copilot — AI Decision Assistant
An intelligent assistant that helps users prioritize tasks and make context-aware decisions using structured prompting and Gemini API.

### 🔍 AI Resume Analyzer & Job Match Assistant
An NLP-powered system that compares resumes with job descriptions using semantic similarity, embeddings, and automated skill extraction.

### 🏭 Machine Health Monitor
LSTM-based predictive maintenance system for Remaining Useful Life (RUL) prediction using industrial sensor time-series data.

### ⚡ Power Demand Predictor
Machine learning-based electricity load forecasting system using XGBoost, weather data, and real-time APIs for smart energy management.

### 💳 Fraud Financial Transaction Detection
Machine learning model for fraud detection using Logistic Regression, feature engineering, and transaction pattern analysis.
